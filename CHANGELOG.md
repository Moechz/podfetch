# Changelog

All notable user-visible changes to the Podfetch TOS application package.

## 5.2.3-1 — 2026-11-11

### Added
- First release. Podfetch (`samuel19982/podfetch:v5.2.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8061 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/podfetchdocker/`.
